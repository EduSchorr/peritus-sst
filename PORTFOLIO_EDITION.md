# Portfolio Edition

This public repository is a sanitized representation of the Peritus SST application.

Removed from the public edition:

- production/case databases and backups;
- generated reports and uploaded evidence;
- real names, case identifiers and professional contact details;
- API credentials and local user configuration;
- private/reference report templates;
- machine-specific paths.

The source remains representative of the architecture, workflow, risk engine, document generation and local application design.
